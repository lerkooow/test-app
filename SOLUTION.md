## Баги из части 2

<!-- Для каждой жалобы: почему так происходило (своими словами) → что исправили. -->

1. Звёздочки:

   Ошибка:

   const isFavorite = (id: string) => Boolean(favorites.indexOf(id));

   В данном случае он будет возвращать неккоректные Boolean значение, так как indexOf() возвращает индекс элемента или -1, если элемента нет

   Исправлено:

   const isFavorite = (id: string) => favorites.includes(id);

   includes() возвращает true, если элемент найден, и false, если нет

   Ошибка:

   if (index === -1) {
   favorites.push(id);
   } else {
   favorites.splice(index, 1);
   }

   push() и splice(), оба изменяют существующий массив

   Исправлено:

   setFavorites((prev) =>
   prev.includes(id)
   ? prev.filter((favoriteId) => favoriteId !== id)
   : [...prev, id]
   );

   filter() создаёт новый массив, если мы удаляем из избранного
   [...prev, id] создаёт новый массив с добавленным в избранное элементом

2. «Обновлено N сек назад»:

   Ошибка:

   useEffect запускался один раз и запоминал значение seconds, равное 0. Каждую секунду таймер пытаелся выполнить setSeconds(0 + 1), поэтому счётчик постоянно пытался установить 1, а не увеличивать число каждую секунду

   Исправлено:

   Был использован пропс since, так как по условию это время последней успешной загрузки данных, поэтому сделала вычисление разницы между текущим временем и since
